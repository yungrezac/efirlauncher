# Логотипы способов оплаты

- Patreon: официальный [Brand Kit](https://www.patreon.com/brand), связанная с ним папка [Logo](https://drive.google.com/drive/folders/1qp6QaHueahJdTwrNQ0A6U8_PMvGEWZ8k), файл PATREON_SYMBOL_1_WHITE_RGB.svg (1NuUGB3rAEEYMSYu8-y_vAXczdQVJXQo8). SVG сохранён без изменения.
- Boosty: значок с официального сайта https://boosty.to/favicon.png?v=15, сохранён без изменения.
- Карта: нейтральная SVG-иконка банковской карты, не логотип платёжной системы. Провайдер оплаты пока не выбран.
- Gram: существующий ресурс приложения Gram_Circular_Badge.webp.

Карта, Patreon и Boosty обозначены «Скоро» и не создают платежей. Для активации нужны соответствующая серверная интеграция и реквизиты.
